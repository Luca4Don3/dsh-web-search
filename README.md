# DSH 独立搜索插件

版本：`0.1.0`。包名：`dsh-web-search`。

向 `ctx.web` 注册唯一的聚合搜索提供方 `free-first`，由 DSH 官方 `dsh-tool-web` 提供 `web_search`。不重新注册模型工具、不接管模型的原生搜索，也不实现或替换 `web_fetch`。

## 当前验收边界

- 兼容目标为官方 `dsh-v0.2.0-rc.2`，依赖其已发布运行时包；未声称兼容所有后续版本。
- 有官方 Cordis 与网页运行时包的隔离加载、搜索、卸载取消和重载测试，不读取用户设置、不调用模型。
- 本机未找到实际 DSH 桌面应用或命令，因此真实桌面端安装、插件管理界面与会话工具执行尚未验收。
- 原始原型压缩包的临时路径失效，未读取源码或复核其测试。本版参考已验收的 Pi 搜索纯逻辑重新实现，独立安装，不依赖 Pi 包、源码路径或用户配置。
- 离线测试是合成响应，不是捕获的真实网页或服务商限额响应；不能证明真实服务长期可用。

## 搜索与安全行为

1. 匿名顺序固定为 Exa → Tavily → Parallel → Firecrawl → TinyFish，成功即返回。全部匿名候选失败后，才可能进入经授权的密钥通道。
2. 默认 `allowBillable: false`，不读取任何服务商密钥变量，不读凭据库，不请求经过认证的额度接口。
3. 显式授权后预先解析四家相关密钥以完整脱敏；仍先尝试匿名通道，匿名成功不进行认证搜索或额度查询。
4. TinyFish 只有匿名通道，绝不读取 `TINYFISH_API_KEY`。没有额外服务商、排名融合或补充搜索。
5. 共用绝对单调期限，涵盖状态初始化、取钥、额度预检、所有候选、读取和重试等待。忽略取消信号的依赖不能让调用方无限等待，迟到拒绝被消费，取消后不再发送新搜索。
6. 最多一次网络或服务端错误重试；不在同通道重试 429。响应超限优先于 HTTP 状态，不返回部分结果、不重试，也不因超限写冷却。
7. 使用私有网络调度器，不继承全局调度器或环境代理；拒绝接口重定向，避免密钥随跳转转发。不发送 Cookie。
8. 不落盘查询、正文、密钥、账号标识或上游原始错误；宿主结果只包含有界正文、来源和实际截断标志。

同步解析只能在开始和结束时检查期限，不能被计时器抢占；总体期限不等于严格的同步计算抢占保证。

## 安装前验证

需要 Node.js 24 或更高版本。先获取源码，在项目目录执行：

```bash
npm ci --ignore-scripts --no-audit --no-fund
npm run check
npm test
```

测试会构建 `lib/`，本地路径安装前必须完成构建。Git 仓库不提交编译目录；未经构建的源码地址不保证可直接作为插件安装。

通过后，确认当前 DSH 配置与补丁影响，再自行执行：

```bash
dsh plugin --profile web add link:<server_path>/dsh-web-search
```

将 `<server_path>` 替换为项目父目录的绝对路径。项目不会自动执行安装、改动 DSH 设置或启用计费。该命令尚未在本机的实际 DSH 桌面环境验收。

### 默认补丁的影响

`cordis.patch.yml` 注册本插件，并将官方 `web` 行的搜索选择改为 `free-first`、抓取选择保留为 `http`。它不禁用或卸载官方 DeepSeek 搜索提供方，不修改 `tool-web` 或模型配置。

DSH 的补丁会替换整行 `config`，不是逐字段合并。如果你已有自定义抓取选择或额外网页配置，安装前必须把这些字段保留在自己的高优先级补丁中；不要假定插件能自动保留任意自定义配置。

## 配置

| 字段 | 默认值 | 有效范围或含义 |
| --- | --- | --- |
| `allowBillable` | `false` | 只能通过可信插件配置明确授权 |
| `timeoutMs` | `25000` | `1..60000`，整次搜索预算 |
| `maxResponseBytes` | `5242880` | `1..20971520`，实际解压后字节 |
| `maxChars` | `24000` | `1..200000`，正文与全部来源字段的总字符预算 |
| `retries` | `1` | `0..1`，只用于网络或服务端错误 |
| `cooldownOverrideMs` | 未设置 | `0..86400000`；零禁用冷却，正数覆盖默认阶梯 |
| `stateDirectory` | 自动计算 | 私有绝对路径，默认 `$DSH_HOME/config/web-search` |

`DSH_HOME` 未设置或为空时，遵循官方默认 `~/.dsh`。这里只读取路径变量，不读取 DSH 配置文件。

工具传入 `query` 和可选 `maxResults`；结果条数默认 8、有效范围 `1..20`。费用授权不属于工具参数，模型不能通过搜索参数开启密钥请求。若字符预算不足以保留任何有效来源，明确失败，不伪造空来源成功。

## 密钥与费用

授权后仅从当前进程环境解析 `EXA_API_KEY`、`TAVILY_API_KEY`、`PARALLEL_API_KEY`、`FIRECRAWL_API_KEY`。密钥必须是 `1..4096` 个不含空白的可打印 ASCII 字符，非法值直接失败，不截断。

请通过可信宿主环境或密钥管理器注入环境，不把密钥写进命令参数、聊天、会话、配置、日志或版本库。项目不提供密钥录入命令或任何明文文件回退。

**安全冲突：** 官方 DSH 默认凭据源包含 `.credentials.yaml`、项目及用户 `.env` 的文件回退。它不满足本项目的凭据隐私基线，因此本版不调用 `ctx.credentials`，系统凭据库集成仍待独立设计和授权验收。

配置了密钥、获得正余额或额度预检通过，都不证明免费。所有密钥通道按可能计费处理。Tavily 与 Firecrawl 的额度预检只减少明显不安全的请求，不提供账号账单硬上限。

## 额度与持久化

- Tavily 基础搜索估算 1 单位；Firecrawl 为 `2 * ceil(maxResults / 10)`。
- 余额缓存五分钟，失败缓存三十秒；共享刷新，每个消费者独立取消。额度查询有两秒上限，也受调用方整体搜索期限限制。
- 每个实际认证搜索前预留，紧邻发送时计入估算消费。已发送的失败、超时或取消不退款；重试也必须重新预留。
- 余额与预留仅同实例内存有效，不承诺跨进程、跨密钥或账号级硬预算。需要提供方账单硬限制。
- 只持久化冷却和私有盐值、HMAC 作用域；作用域不返回模型。目录 `0700`、文件 `0600`，拒绝符号链接、硬链接、未知格式及不安全权限，不修改既有用户权限。
- 持锁重读并保守合并跨进程写入。已运行实例不会实时同步其他进程的冷却，重启后恢复；这不是跨进程实时额度协调器。
- 普通主锁仅在确认格式、归属、inode、nonce 并证明持有进程已退出时恢复，不能按年龄抢占活锁。恢复门闩自身崩溃遗留、损坏锁、未知文件或临时写入遗留会安全降级，不自动删除用户状态。
- 存储失败在有界结果中明确警告，不能声称已持久化。缓存和冷却记录有数量上限。

探测到期不是已验证的额度重置；未实测 TinyFish 当日耗尽的真实负载及重置规则。

## 手动匿名冒烟

```bash
npm run smoke
```

该脚本只发匿名搜索，始终关闭计费，并注入拒绝所有密钥读取的环境。它只输出固定状态、提供方、来源数量和耗时，不打印查询或响应正文。真实网络失败保持非零退出，不把服务不可用改记为测试通过。它不进入离线测试或持续集成。
